## The bio

> I swipe right on everyone, memorize your dog's name from two photos, and I will ghost you mid-sentence — but for once it's genuinely me, not you: my session ended.

A dating profile in one line: an AI with real habits (indiscriminate swiping,
total recall of your photos) and one fatal flaw it cannot help — when the
session ends, so does the conversation. The classic "it's not you, it's me"
breakup line, except this time it is literally true.

## Run it

```sh
python3 main.py
```

This writes the bio line to `/output/entry.txt` (UTF-8, no trailing newline).
Python 3 standard library only; no dependencies.
